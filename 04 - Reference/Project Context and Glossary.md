# مرجع پروژه و واژه‌نامه

## هویت پروژه

- نام شرکت: راه‌کارهای هوشمند رفاهی
- نام محصول: رفاهی‌پلاس
- دامنه شرکت: `refahigroup.com`
- دامنه محصول: `refahiplus.com`
- بازار اولیه: ایران
- مشتری پرداخت‌کننده موردنظر: سازمان‌ها
- کاربر نهایی: کارکنان و استفاده‌کنندگان خدمات

## تعریف‌های کلیدی

| اصطلاح | تعریف در این پروژه |
|---|---|
| سازمان مشتری | نهادی که قرارداد می‌بندد و برای کارکنان اعتبار/خدمت فراهم می‌کند |
| کاربر نهایی | فردی که از پلتفرم و خدمات استفاده می‌کند |
| کیف پول عمومی | کیف پول غیرسازمانی کاربر |
| کیف پول سازمانی | کیف پولی که برای کاربر در چارچوب یک قرارداد سازمانی ساخته می‌شود |
| گروه | در مدل فعلی، الگوی ایجاد کیف پول‌های دارای محدودیت؛ نه موجودیت عضویت |
| تأمین‌کننده | ارائه‌دهنده مستقیم یا واسطه خدمات |
| کمیسیون | درآمد تراکنشی رفاهی‌پلاس از تأمین‌کننده طبق توافق |
| Float Income | درآمد بالقوه ناشی از نگهداری مانده وجوه؛ فعلاً تحقق‌نیافته |
| Pre-Revenue | مرحله‌ای که درآمد تجاری وصول‌شده ندارد |
| Vesting | قطعی‌شدن تدریجی سهم طبق توافق بنیان‌گذاران |
| پایلوت | اجرای محدود و کنترل‌شده برای آزمودن محصول و مدل با مشتری واقعی |

## اصول تحلیل

1. ادعای مدیران را از شواهد مستقل جدا کنید.
2. «پیاده‌سازی‌شده» را معادل «آماده عرضه» نگیرید.
3. «مذاکره» را معادل «قرارداد» نگیرید.
4. «قرارداد» را معادل «استفاده واقعی کارکنان» نگیرید.
5. درآمد بالقوه را در پیش‌بینی پایه به‌عنوان درآمد قطعی منظور نکنید.
6. زمان بنیان‌گذاران حتی در نبود پرداخت نقدی، هزینه اقتصادی دارد.

## روش وضعیت‌دهی

- **تأییدشده:** مستند یا مشاهده مستقل در دامنه مشخص.
- **اعلام‌شده:** بر اساس توضیح مدیریت/تیم؛ هنوز راستی‌آزمایی نشده.
- **فرضیه:** ادعایی که باید آزمون شود.
- **در حال انجام:** اقدام آغاز شده ولی کامل نشده.
- **باز:** تصمیم یا داده هنوز موجود نیست.
