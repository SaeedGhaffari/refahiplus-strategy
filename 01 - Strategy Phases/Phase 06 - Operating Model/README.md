# فاز ۶ — مدل عملیاتی و سازمان

**وضعیت: شروع‌نشده**

هدف، طراحی ساختار حداقلی سازمان، فرایندهای عملیاتی، نقش‌ها، فناوری و سازوکارهای پشتیبانی متناسب با استراتژی است.

موضوعات مورد انتظار:
- ساختار سازمانی حداقلی و RACI
- عملیات سفارش، تأمین و پشتیبانی
- فرایندهای مالی و کنترل
- مدیریت کیفیت و SLA
- زیرساخت، امنیت و تداوم کسب‌وکار
- سیاست استخدام و برون‌سپاری
