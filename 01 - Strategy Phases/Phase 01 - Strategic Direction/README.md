# فاز ۱ — جهت‌گیری استراتژیک

**وضعیت: شروع‌نشده**

هدف این فاز تعیین چشم‌انداز، مأموریت، اهداف بلندمدت، اصول راهبردی، انتخاب‌های کلان و معیارهای موفقیت است.

پیش‌نیاز: تکمیل فاز صفر و انجام تسک 0.10.

سندهای این فاز پس از تصمیم‌گیری ایجاد می‌شوند. سیاست مالی فعلی که پیش‌تر در این مسیر قرار گرفته بود، به‌عنوان تصمیم مدیریتی به پوشه `02 - Strategic Decisions` منتقل و در آنجا نگهداری می‌شود.

موضوعات مورد انتظار:
- چشم‌انداز و مأموریت
- اهداف ۳ تا ۵ ساله
- انتخاب‌های استراتژیک و دامنه فعالیت
- اصول تخصیص منابع
- معیارهای سطح کلان موفقیت
