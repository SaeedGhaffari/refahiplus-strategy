# فاز ۲ — تحلیل بازار و رقابت

**وضعیت: شروع‌نشده**

هدف، شناخت بازار هدف، بخش‌بندی مشتریان، نیازها، اندازه و جذابیت بازار، رقبا، جایگزین‌ها و ساختار رقابت است.

موضوعات مورد انتظار:
- بخش‌بندی بازار و انتخاب بخش‌های اولویت‌دار
- نقش خریدار، تصمیم‌گیر، اثرگذار و کاربر
- نیازها و فرایند خرید سازمانی
- تحلیل رقبا و جایگزین‌ها
- اندازه بازار با فرضیات شفاف
- فرصت‌ها، تهدیدها و روندها
